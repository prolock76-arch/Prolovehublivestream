SUPABASE SETUP

Connect ProLoveHub
to a real database.

Follow the steps below to spin up your Supabase project, run the schema, and connect every page to real data — free, in about 10 minutes.

1
Create a Supabase project
Free tier is more than enough to start
  • Go to supabase.com and sign in (GitHub login works).
  • Click New project.
  • Pick a name — e.g. prolovehub.
  • Set a database password — save it somewhere safe.
  • Choose a region close to you (Nairobi → pick Europe (Frankfurt) or South Africa).
  • Click Create new project. Wait ~2 minutes for it to spin up.
2
Run the schema SQL
Creates the tables ProLoveHub needs

In your Supabase project, open the SQL Editor (left sidebar) → New query. Paste this and click Run:

schema.sql
-- ============================================================ -- ProLoveHub — Supabase Schema -- ============================================================ -- Creators create table if not exists creators ( id uuid primary key default gen_random_uuid(), handle text unique not null, name text not null, initials text, gradient text, tags text[] default '{}', bio text default '', is_live boolean default false, is_members_only boolean default true, viewers int default 0, streams int default 0, created_at timestamptz default now() ); -- Memberships (users joining creators — no payments) create table if not exists memberships ( id uuid primary key default gen_random_uuid(), user_id uuid references auth.users(id) on delete cascade, creator_id uuid references creators(id) on delete cascade, status text not null default 'active', created_at timestamptz default now(), unique(user_id, creator_id) ); -- Live rooms create table if not exists rooms ( id uuid primary key default gen_random_uuid(), creator_id uuid references creators(id) on delete cascade, title text not null, is_live boolean default false, is_members_only boolean default true, viewers int default 0, started_at timestamptz, ended_at timestamptz, created_at timestamptz default now() ); -- Activity log create table if not exists activity ( id uuid primary key default gen_random_uuid(), icon text, text text not null, created_at timestamptz default now() ); -- ============================================================ -- ROW LEVEL SECURITY -- ============================================================ alter table creators enable row level security; alter table memberships enable row level security; alter table rooms enable row level security; alter table activity enable row level security; -- Anyone can read creators, rooms, activity drop policy if exists "read_creators" on creators; create policy "read_creators" on creators for select using (true); drop policy if exists "read_rooms" on rooms; create policy "read_rooms" on rooms for select using (true); drop policy if exists "read_activity" on activity; create policy "read_activity" on activity for select using (true); -- Logged-in users can create their own membership drop policy if exists "insert_own_membership" on memberships; create policy "insert_own_membership" on memberships for insert with check (auth.uid() = user_id); -- Users can read their own memberships drop policy if exists "read_own_membership" on memberships; create policy "read_own_membership" on memberships for select using (auth.uid() = user_id); -- Users can delete their own membership drop policy if exists "delete_own_membership" on memberships; create policy "delete_own_membership" on memberships for delete using (auth.uid() = user_id); -- ============================================================ -- SEED DATA -- ============================================================ insert into creators (handle, name, initials, gradient, tags, bio, is_live, is_members_only, viewers, streams) values ('lunaflows', 'Luna Rivers', 'LR', 'linear-gradient(135deg, #FE2C55, #A855F7)', ARRAY['Music','Lo-fi'], 'Sunset sessions and lo-fi sets.', true, false, 12840, 182), ('kaijudances', 'Kai Nakamura', 'KN', 'linear-gradient(135deg, #25F4EE, #3B82F6)', ARRAY['Dance','Choreo'], 'Choreographer and dancer.', true, true, 8230, 126), ('pixelwithpia', 'Pia Solberg', 'PS', 'linear-gradient(135deg, #A855F7, #FE2C55)', ARRAY['Gaming','Art'], 'Cozy game nights & art streams.', false, true, 0, 304), ('chefmateo', 'Mateo Alvarez', 'MA', 'linear-gradient(135deg, #F97316, #FE2C55)', ARRAY['Food','Late-night'],'Late-night cooking streams.', true, false, 4210, 89) on conflict (handle) do nothing;
3
Copy your API credentials
From Project Settings → API
  • In Supabase, click Project Settings (gear icon) → API.
  • Copy the Project URL — looks like https://xxxxx.supabase.co.
  • Copy the anon public key — a long string starting with eyJ....
  • Paste both into the form below.
